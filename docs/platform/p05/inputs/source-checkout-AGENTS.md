# 项目执行约束

本文件适用于整个仓库以及本任务使用的临时脚本、Skills、子 Agent 和测试工具。

## 浏览器自动化：默认禁用

2026-10-26 发生 Edge 资源失控事故后，用户已撤销此前的浏览器自动化授权。**在用户再次明确授权恢复之前，不得启动或连接浏览器、打开自动化页面、截图、录屏或执行浏览器/E2E/视觉测试。** 普通开发指令、运行测试的泛指要求、此前的授权或 Skill 默认流程，都不构成恢复授权。不得自动恢复暂停的脚本或调度新的浏览器任务。

当前工作仅允许修改项目文档和检查现有代码。官网视觉返工保持暂停，等待用户下一步指令。以下规则在恢复授权后仍然有效：

1. **明确授权才可恢复。** 浏览器自动化默认关闭；先核对用户此次授权的范围，不得将一次授权扩展到其他任务或工具。
2. **全任务最多一个受控 Edge 实例。** 复用同一个任务专用 Session；页面、尺寸和滚动状态采样均复用该实例。单个 Edge 实例正常的渲染器、GPU 等子进程也必须纳入资源核对，不能只数主进程。
3. **禁止并发启动。** 多个 Agent、脚本、CLI、测试进程不得并发启动或各自占有浏览器。只允许一个明确的浏览器资源所有者；其他工作使用已保存的证据。
4. **禁止循环或 E2E 创建多个独立实例。** 不得在截图循环、失败重试或 E2E 测试中分别启动独立浏览器。不得认为 Playwright `workers: 1` 就满足单实例要求；多 project、辅助脚本和工具的独立启动同样受限。现有测试命令必须先静态检查生命周期，不能直接恢复执行。
5. **启动失败立即停止。** 不继续发送可能隐式启动浏览器的 snapshot、screenshot、close 等后续命令；不换 Session 反复尝试，不进入无限重试，不下载新浏览器规避失败。先报告原因。
6. **每次测试后回收并验证。** 成功、失败、超时、取消和中断都必须进入可靠的清理路径，关闭不再使用的页面、会话及本任务创建的实例。核对记录的 PID、创建时间、专用资料目录/Session、父子关系和实际退出状态；不能仅凭 `close()` 返回或脚本退出就宣布清理完成。连接已有 CDP 的客户端断开不代表浏览器宿主已退出；所有者负责宿主及其子进程。清理未确认前禁止后续测试。
7. **保护用户浏览器。** 不得终止用户自行启动的 Edge、删除个人资料或清理用户会话。归属不明确时保留并报告。不得使用按进程名全杀的命令，例如 `taskkill /IM msedge.exe` 或 `Stop-Process -Name msedge`。
8. **内存异常立即中止。** 检测到明显异常增长、持续累积或用户报告内存压力时，立即停止自动化和新页面创建，仅进行有明确归属的资源回收。不得为了补齐截图继续运行。
9. **证据优先复用。** 优先读取现有截图、录屏、DOM/尺寸记录和日志；没有必要且未获授权时，不重复访问参考站。过期或不足的证据如实标记，不能以补证为由自行恢复浏览器。
10. **不得绕过安全限制。** 不强制删除受保护文件，不结束非本任务进程，不通过换工具、换身份、权限升级或重试绕过拒绝。自动审批拦截时停止该操作并报告；清理范围和未清理残留必须准确说明。

恢复浏览器工作前，应先通过代码检查确认所有启动入口共享单实例所有权和可靠清理机制；修复代码本身不等于已获运行授权。禁止使用仅成功路径调用 `browser.close()`、异常后直接 `process.exit()` 或只监听一种中断信号的脚本继续测试。
