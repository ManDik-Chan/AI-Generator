# 单独自查

代码收敛后由同一代理再次从权限入口、失败窗口、数据库触发器及真实报告反查；未使用子代理，不称第三方独立审计。

| 检查 | 发现、修订与复验 |
|---|---|
| 先丢依据后删对象 | 改为源标记与 PENDING 先事务提交；COMPLETE 和源删除同事务；父/账户 cascade 仍保留任务。DB ack 故障及进程退出真实验证 |
| 同类高权限遗漏 | ToolAsset、头像、生成图片、生成失败补偿、过期/维护程序全部追踪到唯一 SDK remove；普通 JWT 不能直接操作清理表 |
| 脏路径授权 | 不信任源记录的前缀声明；完整 owner/resource/scope/kind/bucket/path 校验。发现未知旧 bucket 不应推断，改为显式历史 bucket 授权且默认拒绝；真实负例通过 |
| cascade 重试 | 初版 ON CONFLICT 未晋升 TRACKED，新增迁移修正；损坏 A 引用不能促进 B 的合法任务，三类负例通过 |
| 补偿/附着竞争 | 初版读状态后更新存在窗口；改为共享任务行锁，TRACKED 不可补偿，源附着拒绝退休 key。并发真实测试通过 |
| 数据库完整性 | 源身份/owner/run/bucket 不可改，删除标记不可取消；复合 owner FK 最后实际 VALIDATE，历史错绑拒绝升级 |
| 头像使用竞争 | 标记删除锁定 image；Persona 绑定 trigger 对同一 image 加锁并排除待删，在用头像保留。真实调用拒绝删后附着 |
| 双删/重复投递 | 消费者持任务行锁，COMPLETE 不重开，key 不复用；并发请求及重复消费者通过。不承诺避免所有死锁，错误仍保留任务并返回失败 |
| 元数据/孤儿 | 三类真实专用 bucket 最后对象数为 0；BLOCKED 合成依据不删除。RESERVED 无自动回收 SLA，上传结果未知需人工确认，继续列发布前运维条件 |
| 返回状态 | 仅完成清理及父记录操作后 success；PENDING/BLOCKED/普通失败区分。保留既有 GeneratedImage HTTP 500 message 和原断言，新增状态测试 |
| 读取/TOCTOU | 待删源不再签名/恢复；已经发出的短期签名或正在进行请求不宣称撤回。未来公开资产协议另行验收 |
| 正常功能 | 原成功删除、在用头像及跨用户拒绝断言保留；全部 Vitest、lint/typecheck 通过。旧 bucket 未授权改为明确阻断，是必要安全兼容条件 |
| 产品与视觉 | 没有新 Project 表、路由或 UI，Landing 源码哈希不变；P0.5 输入、CTMR/BYOK/计算边界均保留 |
| 证据完整性 | 两个原失败测试文件未改；历史红灯不覆盖；所有真实套件自动发现，未跳过/删除安全测试或减 required checks |

自查修订后重新执行真实集成及全量回归，结果绑定机器报告中的代码 SHA。仍不能证明的旧迁移 reset/回滚、远端 CI、生产历史 bucket、自动恢复 SLA 与视觉边界全部在风险矩阵中保留，不能用本地绿色结论替代。
