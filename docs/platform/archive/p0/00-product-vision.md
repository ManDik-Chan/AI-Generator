# AIG Platform · P0 产品与范围

> 2026-10-28（Asia/Singapore） · INTERNAL · DRAFT · 等待 Owner 审阅。本文全部目标为 **Inferred / Proposed**，不表示已经实现或批准上线。

## 产品目标

AIG Platform 是隐私优先的开发者成果发布、技术展示和受控运行门户。Project 为一级实体；AI Hub 组合既有 Chat、Persona、Memory、Tools 和 Agents。科研模型、普通 Web 服务、工程工具均可接入；只展示的项目不必具有推理服务或用户凭据。

## P0 已授权工作

依据路线图 §13.1，读取固定版本源码、版本化迁移、安全审计与 CI；交付架构、权限、数据模型、接口草案、CTMR 核验、分 PR 计划和审查结果。只在本地审计目录新增文档及文档校验脚本，不改应用、UI、数据库、远程仓库或设置。

## 不可回归条件

- 保留既有账户、用户数据、AI API、旧 URL 和 Provider 外部行为。新增 `/api/v1` 是提案，不能替换现有 API。
- 当前 Landing 的 `features/landing/*` 是源码视觉权威。用户认可来自本轮输入的既定约束；真实 golden 截图、动效录屏仍须归档和签署。
- Project=PUBLIC 不意味着输入、结果、运行历史或凭据公开。UNLISTED 是链接可见，不是鉴权隔离。
- V1 不运行任意第三方代码，不开放任意 Provider URL，不接收真实医学数据，不承诺临床适用性。
- 不引入计费市场、多组织结算或 CTMR 专有核心字段。
