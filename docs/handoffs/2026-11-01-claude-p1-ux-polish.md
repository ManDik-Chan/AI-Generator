## 2. 修复内容与设计判断

### UX-01 Hero 卡片避让（`landing-runtime.tsx`、`motion-math.ts`）

- 每帧按 CSS 实际使用的变换（相机 `rotateX/rotateY`、`perspective: 1000px`）计算每张卡片的**屏幕投影框**，与受保护区域比较：标题（随滚动缩放上移，同步计算）、底部两段说明（排除为按钮留出的内边距）、页头品牌与右侧控件。
- 卡片进入受保护区域 10px 内时不透明度为 0，向外 48px 内平滑恢复。卡片仍然从标题后方飞出，只是在经过文字时隐去，看起来像从标题背后浮现；数量、速度、轨迹、景深淡入淡出均未改变。没有删除卡片，也没有重做 Hero。
- 受保护区域使用布局偏移量（不受入场动画变换影响），在 `measure()`（启动、字体就绪、加载完成、预加载结束、尺寸变化）时更新；卡片尺寸同时测量。
- `prefers-reduced-motion` 下卡片静止，避让照常生效。

### UX-02 悬浮按钮通道（`landing.css`）

- 新增 `--fab`（48px，≤600px 为 44px）与 `--fab-lane`（按钮宽度 + 14px）。Hero 底部第一段与**整个**页脚底行使用该通道作为左内边距，纵向排列时两行都避开按钮。按钮本身的尺寸、位置、色调切换不变。

### UX-04 页头色调切换（`landing.css`、`landing-runtime.tsx`）

- 页头文字与胶囊底色在色调切换时同一帧完成，不再交叉渐变，消除 1:1 的中间帧。白色↔青柠的胶囊底色（`goo`）仍保留渐变，因为墨色文字在整个过程中对比度都足够。
- 色调判定点从固定的 `scrollY + 40` 改为页头控件行的垂直中点（实测），区块边缘经过文字时才切换。
- 语言切换按钮是页头中唯一没有底色的控件。为它加上与胶囊一致的磨砂底：浅色调 `rgba(255,255,255,.64)`，深色调 `rgba(242,239,234,.78)`，文字固定为墨色。在任意背景（纯黑到纯白）上对比度 ≥ 4.5:1，内边距与宽度不变，不影响 320px 页头布局。
- 品牌字标属于标识，WCAG 对比度要求不适用，保持随色调翻转。

### UX-06 动画文字的语义（`primitives.tsx`、`roll-text.tsx`、`landing.css`、`globals.css`、`landing-runtime.tsx`）

- `Roll` / `RollText`：标签只保留**一个真实文本节点**，静止时显示的就是它。滚动动画的字形改为 `aria-hidden` 层中由 `::before/::after { content: attr(data-c) }` 生成；生成内容不会被选中、复制、翻译或进入文本提取。悬停/聚焦时切换到动画层，回滚结束后再切回真实文本（延迟按字符数计算）。关闭字距调整与连字，保证真实文本与逐字符动画层逐字对齐、切换无跳动。去掉了 `sr-only` 副本，可访问名称直接来自真实文本。
- 翻译：Chrome 翻译会给 `<html>` 加 `translated-*` 类，CSS 据此隐藏动画层；落地页运行时另用 `MutationObserver` 检测标签文字被改写（适用于任何在 DOM 中改写文字的翻译器），改写后保留翻译文字、停用动画层。共享 `RollText` 没有运行时，依赖 `translated-*` 类；其他翻译器下静止文字正确，只有悬停时会显示原文动画（已知限制）。
- `Chars`：不再为每个字符生成元素，段落保持纯文本。逐字点亮改用 **CSS Custom Highlight API**：运行时用 `Range` 标出未读部分（及阅读前沿字符的 3 级过渡亮度），通过 `::highlight()` 着色，DOM、选区、复制、查找、翻译与屏幕阅读器都不受影响。节奏与原实现一致（`charFrontier`）。不支持该 API 的浏览器直接显示完全点亮的文字；文字被翻译改写后停止着色。
- Hero 卡片层与章节编号层加 `user-select: none`，作为补充，不是主要修复手段。
- 动画前后语义不变：所有动画只改变绘制（变换、可见性、高亮），文本节点与无障碍树不变。

### UX-10 / UX-11 登录页（`app/(auth)/layout.tsx`、`login/page.tsx`、`register/page.tsx`）

- 品牌面板标语由 `<h1>` 改为 `<p>`，样式与入场动画不变；表单标题是页面唯一的 `<h1>`。登录与注册共用布局，同时生效。
- 两个表单标题加 `text-balance break-keep break-words`：只在“AI”两侧的空格处断行（“登录你的 / AI 空间”），行宽均衡；超长时 `overflow-wrap: break-word` 兜底，避免 200% 文字缩放下溢出。

### 视觉验收后的两处排版修复（`landing.css`）

- 标题的每一行（`.line > span`，Hero 与 Closing）加 `text-wrap: balance`。每行是独立块，只有放不下需要换行时才生效，不改变不换行的标题。英文 Hero 在手机宽度下由“Show what you / make,”变为均衡的两行。
- 中文 Forest 引言按设计是固定三行。字号由 `t-h2` 的 `4vw` 改为 `clamp(32px, 3.6vw, 64px)`（仅中文），最长一行在 961px 以上都能放进六列宽度（余量 ≥ 20px），桌面字号约小 10%。≤960px 引言占满宽度，不受影响。

## 5. 剩余风险

- 动画层与真实文本的对齐依赖“关闭字距与连字后逐字宽度之和相等”。Edge 实测最大偏差 0.23px；其他浏览器与字体回退未实测。
- CSS Custom Highlight API 需 Chrome 105+、Safari 17.2+ 或较新的 Firefox；不支持的浏览器显示完全点亮的文字（不影响阅读）。Chrome 的查找高亮与选区在高亮文字上的表现未目测。
- 卡片避让使用近似投影（忽略卡片平面自身的倾斜，最大约 6°），有 10px 安全距离；E2E 采样会在 CI 中验证。
- 共享 `RollText` 在非 Chrome 翻译器下悬停仍显示原文动画（静止文字正确）。
- 语言按钮的磨砂底是可见的设计变化（原为纯文字）；视觉验收中与胶囊行协调，深色调下略偏灰。
- 中文 Forest 引言桌面字号约小 10%，未再次目测。
